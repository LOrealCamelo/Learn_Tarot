# Ink & Intuition

A personal, upright-only tarot study web app. The interactive study deck, quizzes and progress tracker live in `index.html` and use browser-local storage. No readings or spreads.

Card art: place legitimately owned images under `assets/cards/` using the filenames documented in the app; the built-in illustrated fallback makes the app usable before art is supplied.

This repository was empty when work began on November 16, 2026. This initial README establishes a safe base commit; app development will occur in a separate branch and pull request.
